                      ＳＭＦナイフ for Win32 v2.61a



  ＳＭＦナイフは、ある音源用に作られたＳＭＦデータを他の音源でも再生できるよ
  うにＳＭＦを補正変換するソフトウェアです。

  ＳＭＦナイフは、「コンフィグファイル」という音源間の補正値を書き込んだテキ
  スとファイルを元に変換しますので、別途「コンフィグファイル」が必要です。
  本フルパック版には「標準コンフィグファイル集 v2.54」及び「SMFK32.DLL」が
  同封されています。

  ＳＭＦナイフ for Win32はシェアウェアです。試用期間は３週間です。
  試用期間を過ぎると FORMAT 1 のＳＭＦを変換することができません。

  SMFK32.DLLとSMFナイフ for Win32本体とは、別々にパスワードを登録する必要が
  あります。パスワードは同一です。 詳しくはヘルプをご覧ください。

  V2.61 より DLLと本体の変換ルーチンが全く同じになりました。そのため、
  /Pオプションなど、以前は本体のみでサポートしていた機能もDLLから利用
  可能です。

  本アーカイブはフォルダ付き書庫となっております。
